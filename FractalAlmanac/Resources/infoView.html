Zooming into the Current Model

Tap, Hold, and Drag your box to zoom. To make zooming more acurate for where you want to dive into, the box is centered on the initial zoom tap. The fractal model will then regenerate and render with these new extents. If you aren't happy with where you ended up, just tap the ⏪ button and you'll move back to the previous extents.

Due to precision limitations, you will only be able to zoom so far down. It is at this point that the computational accuracy of the device cannot correctly resolve values between the given extents. Hopefully, someday this precision can be improved.

Navigation

You can use either the ⏪ menu button to move back one zoom level, or ⏮ will reset back to the initial state of the rendered model. If you had previously loaded a Bookmark, the rendered model will go back to those initial extents.

Screenshots

You can take a photo of the currently rendered model and save it directly into your Photos app. Fractal Almanac will prompt you once for permissions to access Photos. Once an screenshot is captured, you can continue to explore or immediately navigate to Photos and work on that image as you so desire.

Palette Generation

By selecting the Customize... option in the Palette menu, you will be presented with an editor to create a whole new color palette. Explore your creativity here and select colors that match what you are looking for. You also have the option to apply generic filters as part of the Palette:

Glow
Applies an interpolated glow along color borders.
Blur
Applies a generic light blurring of the final image. This works well with a custom Palette that has many gradient colors.

Palette Editing

By applying a Long Press on any Palette, you will bring up the same Palette Editor. From here you can edit your Custom palette or save existing palettes with new color combinations as new Palettes. You cannot save edits to the Classic or Enhanced palettes.

You can also enable an Interpolation of the selected colors to span more levels of the rendered model. The interpolation count is between 16 and 64. See what interesting color palettes you can make once you edit and Palette that has many colors in it.

Model Selections

Model selection is pretty straightforward here. Select the Model menu item and then select which model you want to start exploring. All navigation from the prior model is reset once a new model is selected. Your current Palette selection is used with the new model.

Saving Bookmarks

If you found a really cool area in a model that you'd like to explore later, you can save a Bookmark of the Model, Palette, and Extents currently displayed. From this menu, you can save new Bookmarks as well as load previous locations and create new Bookmarks from there. A standard left swipe on a Bookmark will remove it permanently from the app.

Advanced Options

Editing Current Extents

Perform a Long Press anywhere on the Extents view at the top of the rendered image. This will activate the Edit mode were you are able to direcly enter discrete extent coordinates. You should know of a known location to enter here, as just setting random values will either bring you somplace semi-booring or fail validation.

Your supplied extents should be "square" in that the spans between the X and Y axis extents must be equal.
